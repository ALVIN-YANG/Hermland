# 第三方组件

Hermland iOS 使用 Apple 开源的 SwiftNIO SSH（0.13.0）与 NIO Transport Services（1.27.0），以及 Package.resolved 固定的传递依赖。它们分别按 Apache-2.0 等各自许可证分发。原始许可证和 NOTICE 已汇总在 `Resources/ThirdPartyNotices.txt`，随 App 分发，可从「使用与隐私说明 → 开源组件与许可证」查看。升级依赖时须同步核对和更新此文件。

- [SwiftNIO SSH](https://github.com/apple/swift-nio-ssh)：SwiftNIO project authors；Apache-2.0。
- [NIO Transport Services](https://github.com/apple/swift-nio-transport-services)：SwiftNIO project authors；Apache-2.0。
- [SwiftNIO](https://github.com/apple/swift-nio)：SwiftNIO project authors；Apache-2.0。
- [Swift Crypto](https://github.com/apple/swift-crypto)：Swift Crypto project authors；Apache-2.0，依赖所含密码学组件的许可证另见上游。
- [Swift Atomics](https://github.com/apple/swift-atomics)、[Swift Collections](https://github.com/apple/swift-collections)、[Swift System](https://github.com/apple/swift-system)、[Swift ASN.1](https://github.com/apple/swift-asn1)：各项目作者与对应上游许可证。

转发处理参考了 SwiftNIO SSH 示例中的字节封装、回压和半关闭机制。原项目版权：Copyright (c) 2020 Apple Inc. and the SwiftNIO project authors。许可证：https://www.apache.org/licenses/LICENSE-2.0 。
