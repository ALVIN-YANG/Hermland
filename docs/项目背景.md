# Hermland 项目背景

Hermland 是连到自托管 Hermes Agent 的远程客户端。手机和另一台 Mac 只做遥控器，Agent 仍跑在家里的机器上。

名字取 Hermes + land，和 PocketClaw 的 Clawland 同类：短、好记、不蹭已有商标。不用 Hermly——App Store 已有同名健康应用。

## 从哪来

家里有两台 Mac：

| 机器 | 角色 |
|---|---|
| Mac Mini `192.168.3.150`（`ylqdeMac-mini.local`，Intel，macOS 15.7） | 常驻 Hermes |
| 日常用的 MacBook | 开发 Hermland、需要时当桌面客户端 |

Mini 上已经做完这些事：

- 卸掉 OpenClaw（网关、LaunchAgent、`~/.openclaw`、全局 npm 包）
- 装上最新 Hermes Agent **v0.20.1** 和桌面端 **0.17.0**（`/Applications/Hermes.app`）
- 默认模型为 DeepSeek 官方 **deepseek-v4-flash**，走 `https://api.deepseek.com/v1`

本机 MacBook 上的 Hermes 已按要求清干净，不再保留第二套 Agent。

出门或离开 Mini 时，现在只能靠 Telegram 一类聊天通道，或再装一套官方 Desktop 做远程网关。没有自己的、专门对着这台 Mini 的口袋客户端。

## 对标

[PocketClaw](https://apps.apple.com/us/app/pocketclaw-control-ai-agents/id6759418062)（Rethinking.Studio）把手机做成 OpenClaw / Hermes 网关的薄客户端：

1. Agent 留在用户自己的机器上
2. App 用扫码或手输配对到网关
3. 同步当前会话和上下文，继续聊
4. 看网关状态、发远程命令
5. 数据走用户自己的环境，不经过对方的云

Hermland 学的是这条链路，不是再做一个 Hermes，也不是再做一个通用「Hermes AI」聊天壳。

Nous 没有官方 iOS App。官方路径是 Telegram / WhatsApp / 微信 / Discord，或 Desktop 连远程 `hermes serve`。社区里已有 Scarf、Hermex 等第三方，和 PocketClaw 抢同一入口。Hermland 只服务自己这套 Mini 上的 Hermes，不为上架去对标它们的功能清单。

## 技术前提

Mini 上的 Hermes 已经带官方远程面：

- `hermes serve`：Desktop 和远程客户端用的 JSON-RPC + WebSocket 网关，默认端口 `9119`
- `/api/ws` 聊天，`/api/sessions` 会话
- 账号密码、session token、配对码
- `hermes dashboard` 是同一后端上的浏览器管理台，不是必须装进 App 里的东西

第一版先同一 Wi‑Fi 通，出门再用 Tailscale 一类组网。不要把 dashboard 裸绑到公网。

## 要做成什么样

手机或另一台 Mac 打开 Hermland，配对到 Mini，就能接着家里那套会话聊天、看到网关在不在、把想法发回去执行。会话和记忆留在 Mini 的 `~/.hermes`，不在客户端另存一套大脑。

### 第一刀

- iPhone，以及这台 Mac 上的桌面客户端
- 连 `192.168.3.150` 上的 `hermes serve`
- 配对（扫码或手输地址 + 凭证）
- 会话列表、续聊、网关是否在线
- 局域网先通

### 先不做

- 自研 Agent 或替换 Mini 上的 Hermes
- skills 市场、多 Agent 编排、订阅内购
- 把模型 API Key 写进手机
- 再装回本机 Hermes 当第二套后端

## 非目标

- 不叫 PocketClaw、Hermly、Hermex、Scarf、Clawland（均已占用）
- 不做云托管 Hermes
- 不把 Mini 暴露成无鉴权的公网服务
