# Connecting to your home agent: choose a route

[English](外网连接方案对比.en.md) · [简体中文](外网连接方案对比.md)

Hermland fits one existing agent, a trusted VPS you already own, and manually registered device keys. If you want less server maintenance and do not have a VPS, consider Tailscale. For browser-only access, consider Cloudflare Tunnel + Access if its trust boundary is acceptable. These are recommendations based on the tradeoffs below, not performance or security rankings.

| Route | Advantages | Cost and trust boundary |
| --- | --- | --- |
| Hermland: two SSH tunnels and your VPS | Both ends connect outbound; no home public IP, inbound router port, or domain required. Uses macOS SSH. Each manually approved key gets one relay port; the app provides setup material and checks. | Maintain the VPS, SSH, and home Mac. The HTTP traffic meets at the VPS, whose administrator must be trusted; this is not client-to-home end-to-end encryption. First setup still requires deployment. |
| Tailscale | Helps establish direct connections, with encrypted relay fallback; usually no self-rented VPS needed. Supports device approval and port rules. DERP cannot decrypt device traffic. | Install clients and manage an account and policies. Coordination-service and network availability matter. Approval and least privilege require configuration. This is not a Hermland mode. [Setup](https://tailscale.com/docs/how-to/quickstart), [DERP](https://tailscale.com/docs/reference/derp-servers), [approval](https://tailscale.com/docs/features/access-control/device-management/device-approval), [port rules](https://tailscale.com/docs/features/access-control/grants). |
| Self-hosted WireGuard | Own the peer keys and network without a hosted mesh account; useful for several home services. | Configure reachable peers, routes, firewalls, clients, and revocation. Encryption depends on its endpoints: a VPS that terminates both tunnels can read forwarded traffic not separately end-to-end encrypted at the application layer. [Official setup and NAT guidance](https://www.wireguard.com/quickstart/). |
| Cloudflare Tunnel + Access for a published web app | Home `cloudflared` connects outbound, without a home public IP. Provides a browser entrance with access rules, without a traditional self-managed VPS. | Usually needs a domain, Cloudflare account, connector, and Access policy. User login alone does not restrict access to a particular computer. For proxied HTTP, TLS terminates at Cloudflare, so trust it to process request content. Test agent login, WebSockets, and pairing. [Tunnel](https://developers.cloudflare.com/tunnel/), [Access policies](https://developers.cloudflare.com/cloudflare-one/access-controls/policies/), [two TLS connections](https://developers.cloudflare.com/ssl/get-started/). |
| Direct SSH to home | No application-traffic relay server. Authenticate using device keys and forward the original web port. | Home SSH must be reachable externally; public IPv4/IPv6, forwarding, and firewall work may be needed. Maintain that exposed SSH service, not a public raw agent WebUI. This is not a current Hermland mode. [OpenSSH encryption and forwarding](https://man.openbsd.org/ssh.1). |
| frp | Flexible tunneling for several services; STCP avoids directly exposing the target port publicly. | Maintain server/client programs and access rules. STCP also needs a visitor client and matching shared secret, not independent device public keys. Tunneling does not replace agent login or device permissions. [Official STCP guidance](https://gofrp.org/en/docs/features/stcp-sudp/). |

All routes require an online home agent. Signing and notarization address the downloaded app's publisher, integrity, and Apple scanning, not connection authorization or model availability. Keep the original agent login and verify a real model response. [Apple notarization](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution).

The alternatives have not been accepted as Hermland connection modes. No regional speed or availability is promised; verify login, WebSockets, revocation, and recovery on the chosen route. Sources checked on 2026-10-13.
