# 首次连接界面

0.2.0 按用户确认的四页设计实现：欢迎 → 准备服务器 → 发连接卡 → 导入并检查。两端复用 `ui/` 的布局、颜色、插画和服务器信息校验；连接逻辑仍由原平台实现处理。

控件不随窗口横向拉长。Mac 正文 17 pt、辅助文字 16 pt，主按钮宽度最多 340 pt、高度至少 52 pt；输入框至少 50 pt 高，地址与端口一组最多 560 pt 宽。iOS 采用系统动态字体，并按可用宽度收缩控件。

## 主路径

- 欢迎页只选择自己已有的 Hermes / OpenClaw。已有 JSON 可直接导入；已有其他设备能连接时，走新增设备分支，不重建中转。
- 首次部署先填写自己的服务器地址与 SSH 端口，并由用户确认已有可信管理员登录。填写不发起网络请求，也不替换已保存连接。未准备好服务器时提供购买、地址与可信登录指引；不代购、不接收管理员密码或私钥。
- 连接卡包含本机公钥、指纹、服务器信息和完整配置约束。Mac 复制，iPhone 使用系统分享面板；用户回到原 Agent 对话手动发送。复制、发送、人工授权是三个不同动作。
- 导入后先显示目标、服务器指纹和来源核对。用户确认后才替换配置并连接。取消不改原路线；错误输入不会进入连接卡。链路通过后仍须完成原网页登录，由用户发消息确认回答。

首次部署要求常驻 Mac、中转 VPS、原 Agent 和必要的执行权限。App 的引导不能消除服务器购买、首次信任建立、人工授权或原网页登录；没有权限时停在当前步骤，使用手动备用方式。

## 保持不变

手动发送公钥、逐设备授权、固定服务器公钥、仅回环转发、拒绝未授权设备和撤销后的重连。没有公网连接申请、自动批准或共享私钥。两段 SSH 不提供绕过 VPS 的端到端加密。原模型、配置、记忆和会话不迁移。

## 插画

运行素材：`ui/Assets.xcassets/ConnectionScene.imageset/connection-scene.png`。使用内置图像生成工具，从已确认的欢迎页中单独重绘透明插画；所有文字、控件和状态均由原生 SwiftUI 渲染，图片不充当假界面或连接结果。

提示词：仅保留左侧家中桌面电脑、上方中间的中转云、右侧笔记本与手机，使用原设计柔和哑光、浅木色桌面、矿物蓝和细暖金路径。移除窗口、背景、所有文字、图标品牌、按钮、人物、鸟和勾选状态；输出有留白的透明独立素材。Mac 图标不变。

## 验证边界

本地自动化覆盖服务器信息校验、配置导入、公钥材料、身份固定、未授权拒绝及隔离 SSH 撤销。原生预览覆盖主路径、无服务器分支和取消导入。发布证据另见对应 Release 与 `docs/发布与验收.md`，不要把设计图、编译或本地预览当成普通用户跨网络验收。
