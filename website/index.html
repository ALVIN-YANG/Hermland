01 / SETUP

三步接入，不再来回填配置。

推荐让你平时使用的 Agent 协助；没有执行权限，就按内置手动步骤完成。人工授权不省略。

  1. 1

    复制材料，手动发出

    选择已有后端，点「复制配置材料」。公钥、指纹和指令一起发给原 Agent 或可信管理员，不发到尚未连通的 Hermland。

    可验证：材料含本机公钥，不含私钥或令牌。
  2. 2

    核对指纹，确认授权

    对方报告电脑和指纹后，由你明确确认。首次配置时，常驻机公钥也要另行手动核对。没有主动申请或自动批准。

    可验证：授权记录的指纹与要授权的机器一致。
  3. 3

    导入配置，检查并使用

    点「导入并检查…」，确认配置来源和服务器指纹后自动检查。再完成原网页登录，由你发一条消息验证真实回答。

    可验证：四项检查通过，原会话可见，模型真实回答。

第一次：准备或复用中转，只补缺失组件。

新增电脑：只授权新公钥，不重装 Agent 或重建隧道。

日常：打开 App，用已保存的配置自动连接。

02 / HOW IT WORKS

两端主动连接，网页还是原来的。

信任什么，不信任什么？

公钥可以发送，私钥留在本机。SSH 验证你持有已授权公钥对应的私钥；App 同时核对固定的服务器公钥。知道 IP、公钥或 JSON，不等于能够接入。

必须信任 VPS 管理员：两段 SSH 不是客户端到家里的端到端加密。客户端其他本机程序也能访问已打开的回环端口。原 Agent 登录保留，不应关闭。

04 / BEFORE YOU CONNECT

用对它，比多一个按钮更重要。

为什么不直接用 Tailscale / VPN？

我们只做一个 Agent 网页的专用入口：复用自己的 VPS 与 macOS SSH，不再安装 VPN 客户端或接入托管组网账号，人工授权一台电脑访问一个中转端口。不是因为 Tailscale 不安全；它也支持设备审批与端口限制，而且 DERP 中转无法解密端到端加密流量。我们的双 SSH 必须信任 VPS 管理员，并由你维护 VPS，不保证首次安装更简单。已有 Tailscale、要访问多个服务或需要中转不可解密时，可以继续用它；当前 App 没有 Tailscale 模式，也不改你的 VPN。

Tailscale: Device approval · Grants · DERP

家里的 Mac 关机或睡眠，还能用吗？

不能。常驻 Mac 需要联网、保持用户登录并且不睡眠；当前用户登录服务不是关机唤醒服务。

四项检查都绿了，为什么模型还不能回答？

检查仅验证配置、设备密钥、SSH 与后端健康，不发送模型任务。请在原页面完成登录，再由你验证真实模型回答。模型凭据和会话仍由原 Agent 管理。

电脑丢了，怎样撤销？

在 Mini 或其他管理电脑，通过可信管理员 SSH 撤销该设备公钥。它的已有连接会断开，新连接会拒绝，不删除原会话，也不影响其他设备。当前没有管理 GUI。

需要屏幕录制、辅助功能或 autossh 吗？

Hermland 不需要屏幕录制或辅助功能。Agent 桌面工具的权限独立设置。新中转使用 macOS 自带 launchd 与 SSH，不要求另装 autossh；已有服务不改动。

没有 VPS，或 Agent 在 Linux 服务器上怎么办？

当前这条配置路径需要自己的 Debian/Ubuntu VPS 和常驻 Mac。没有服务器购买服务，不提供未经验证的一行安装器；直连 Linux Agent 不是此版本的支持模式。

这个网站会保存我的公钥或聊天吗？

不会。本站是静态介绍页，没有账号、表单、连接申请或聊天后端，不使用分析脚本。浏览与下载由 GitHub 托管；App 的流量经过你自己的 VPS。
