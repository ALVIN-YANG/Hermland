开始前

认识这三个角色，就不容易走错。

Hermland 是连接工具，不是云端 Agent。首次配置需要下面这些；以后打开 App 就能用保存的配置连接。

家里的 Mac

Agent 在这里工作

你已有的 Hermes + WebUI，或 OpenClaw Gateway + Control UI。保持联网、用户登录、不睡眠。

你的云服务器 · VPS

在两台 Mac 之间转接

自己准备 Debian / Ubuntu 服务器，由你信任的人管理。不需要域名，也不用给家里路由器开端口。

外出的 Mac

在这里打开 Hermland

macOS 14 或更新版本。只安装 Hermland，不用再安装一份 Hermes / OpenClaw，也不用重新填写模型密钥。

还没有 VPS？从这里准备

VPS 就是你租用的一台云服务器，费用由云厂商收取。它只转接连接，不用把 Agent 搬过去。

  1. 在你信任的云厂商创建 Debian / Ubuntu 服务器，记下公网 IP 和 SSH 端口（通常是 22）。
  2. 通过云厂商控制台核对服务器身份，再由你或管理员确认能用 SSH 登录。不熟悉这一步，请先找可信的人协助。
  3. 回到 App 填入 IP 和端口。接下来让原 Agent 协助配置中转；填地址本身不会安装软件或授权设备。

第一次连接

配置交给原 Agent，授权由你确认。

继续用你平时与 Hermes / OpenClaw 对话的入口。它有执行权限时可以协助配置；没有权限，就由你或管理员按手动指南执行。

  1. 1

    打开 App，填服务器地址

    在外出的 Mac 选择已有的 Hermes / OpenClaw，点「开始连接」。填写自己的 VPS 地址和 SSH 端口，确认你或管理员已能可信登录。

    这一步完成：服务器准备好了。还没准备好？先看上面的 VPS 指引。

  2. 2

    发连接卡，核对后授权

    点「复制连接卡」，回到原 Agent 对话粘贴发送。卡片已带上本机公钥和配置指令。核对它报告的设备名、公钥指纹，再明确回复同意授权；首次配置还要核对家里 Mac 的公钥。

    这一步完成：收到一个 .json 连接文件。没有执行权限，就点 App 内的「查看手动方式」。

  3. 3

    收回文件，导入就能检查

    把文件保存到这台 Mac。点「我收到连接文件了」，选择它，核对可信来源与服务器指纹后确认连接。四项检查通过，再完成原网页登录，发一条消息确认 Agent 能回答。

    这一步完成：看见原会话，并收到真实回答。健康检查不会代你发送模型消息。

信任边界也说清楚

必须信任 VPS 管理员：两段 SSH 不等于两台 Mac 之间端到端加密。原 Agent 登录要保留；本机其他程序也能访问 App 已打开的本地端口。

你可能还想问

为什么不用 Tailscale / VPN？

Hermland 专门连接一个 Agent 网页，复用你自己的 VPS 和 Mac 自带 SSH，不额外加入 VPN 网络。代价是自己维护服务器，首次配置不一定比 Tailscale 简单。这不是“比 Tailscale 更安全”：它也有设备审批和访问规则，其 DERP 中转不能解密端到端加密流量；我们的 VPS 管理员必须可信。已有 Tailscale、需要访问多个服务，可以继续用它，不必为 Hermland 拆掉现有方案。当前 App 没有 Tailscale 模式，也不会修改 VPN。

家里的 Mac 睡眠或关机了怎么办？

需要先恢复联网、登录并保持不睡眠。Hermland 不会远程唤醒关机的 Mac。当前这条初始化路径要求 Agent 运行在 Mac，暂不支持把 Linux Agent 作为常驻端。

检查通过，但 Agent 没有回答？

四项检查只验证配置、设备密钥、SSH 和后端健康，不验证模型。请完成原网页登录，再发一条消息测试；模型账号、额度和会话仍在原 Agent 管理。

电脑丢了，可以只撤销那一台吗？

可以。管理员通过可信 SSH 撤销该设备公钥，已有连接会断开，新连接被拒绝；不删除聊天、不影响其他设备。当前这项管理用命令行完成，没有管理界面。

查看授权与撤销指南 ↗

要给屏幕录制权限，或安装 autossh 吗？

Hermland 不需要屏幕录制或辅助功能。Agent 桌面工具的权限是另一回事。新中转使用 Mac 自带的 launchd 和 SSH，不要求另装 autossh，已有服务保持不变。

打开时出现系统安全或钥匙串提示？

首次“是否打开”是正常系统确认。钥匙串提示请核对 Hermland 后自行允许，不删除设备密钥。如果提示无法验证开发者，请核对下载来源、版本与校验值并反馈，不要关闭 Gatekeeper 或运行去除保护的脚本。
