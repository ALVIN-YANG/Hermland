Hermland

隐私说明

更新日期：2026 年 10 月 13 日。Hermland 是连接你自有 Hermes WebUI 或 OpenClaw Control UI 的客户端。维护者不运营聊天或连接代理服务器。

本机保存什么

连接地址、端口、后端类型、设备账户和已核对的服务器公钥保存在设备本地。iOS 的独立设备私钥保存在本机钥匙串，设为仅本设备、解锁时可读，不通过 Hermland 同步到其他设备。

原网页的登录状态、缓存与网页存储由 WebKit 保存，并按连接路由隔离。你复制或通过系统分享面板发出的连接卡包含公钥、指纹、你填写的服务器地址与端口，以及配置说明；发送目标由你选择，材料不包含私钥、管理员密码或模型凭据。

内容发给谁

连接与聊天流量发往你指定的 VPS 和 Agent。双 SSH 分段加密，VPS 管理员属于可信边界，能够接触中转内容。原 Agent、它加载的外部资源及模型服务仍可能按各自规则处理数据；请核对你使用的服务和部署。

Hermland 本身不嵌入广告、分析或追踪 SDK，不将你的聊天、公钥、连接地址或凭据发送给维护者。你主动打开项目、支持或其他外部链接时，对应网站会接收正常的网络访问。Apple 可能根据你的系统诊断和 TestFlight 设置处理崩溃与反馈，详情以 Apple 的说明为准。

权限与删除

局域网权限仅用于连接你配置的局域网 SSH 服务器。Hermland 不要求屏幕录制、辅助功能、通讯录、相机或麦克风权限。

App 内“移除此连接配置”清除本机连接记录，并停止当前连接；它不删除原 Agent 的会话，也不撤销服务器授权。永久停用或丢失设备时，应由管理员撤销该设备公钥。钥匙串身份可能在卸载后保留，重装不能替代服务器撤销。原网页会话、模型服务数据和服务器日志由你或对应服务管理。

支持

普通问题可通过 项目支持联系维护者。请勿在公开 Issue 中发送地址、凭据或聊天。安全问题使用 私密漏洞报告。

Privacy

Updated October 13, 2026. Hermland connects to your own Hermes WebUI or OpenClaw Control UI. The maintainer does not operate a chat or connection relay service.

Connection settings and the reviewed server public key stay on your device. The iOS device private key is stored in Keychain with a device-only, when-unlocked policy. Hermland does not sync it. WebKit stores the original page's login state and website data, isolated by connection route. A connection card you copy or share includes the public key, fingerprint, server address and port you entered, and instructions; never the private key, administrator password or model credentials. You choose where to send it.

Traffic goes to the VPS and Agent you configure. The two SSH channels encrypt each network segment; the VPS administrator is trusted and can access relay content. Your Agent, external resources it loads, and model providers have their own data practices.

Hermland includes no advertising, analytics or tracking SDK and does not send your conversations, keys, connection addresses or credentials to the maintainer. Opening external support or project links makes a normal request to that website. Apple may handle diagnostics, crashes and TestFlight feedback under your system settings.

Local network permission is used only to connect to your configured local SSH server. Hermland does not request screen recording, Accessibility, contacts, camera or microphone permissions. Removing a connection deletes local configuration and ends the connection; it does not delete Agent conversations or revoke server authorization. An administrator must revoke the device's public key when the device is lost or retired. The Keychain identity can survive uninstalling the app. Server and model-provider data remain under your or the provider's control.

Contact the maintainer through project support. Never post secrets or conversations in a public issue. Use private security reporting for vulnerabilities.
